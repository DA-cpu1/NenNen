Use case: ui-mockup
Asset type: Windows桌面陪伴应用，完整首版“记忆操作”全部关键弹窗与状态设计板。
Input image 1: 参考视觉体系，不复制页面内容：暖白底、淡紫强调、深蓝中文、轻边框、Windows11界面、成熟安静的桌面工具。
Primary request: 生成2560x1800高分辨率横向UI设计板，均匀三列两行共六张很大的弹窗/局部状态卡片。每张内容可读，每个弹窗右上有关闭X，卡片外编号与标题。顶部“06 / 记忆操作与边界状态”，右上角“完整首版界面 · 设计稿”。不是页面原型骨架，是真实成品UI状态图。简体中文清晰，不要花哨插图。每个面板各自完整，不互相遮盖。

01「编辑纠正」
弹窗标题“纠正记忆”，字段标签“当前内容”，只读浅灰框“你希望被称为「阿达」”。字段标签“改为”，多行编辑框“你希望被称为「小陈」”。范围标签“仅六花可用”。说明“保存后会保留旧记录，并让新内容生效。”。底部左“取消”，右紫色主按钮“保存纠正”。

02「忘记确认」
弹窗标题“忘记此信息”，内容卡“你现在不喝咖啡”。默认选中一个圆形单选项“忘记此信息（聊天原文仍保留）”。下一行独立方形复选框，明确未勾选，“同时删除原文”。提示小框内三条清晰可读短句：
“忘记后，整条来源消息不再参与回复和记忆整理，可能影响同条消息里的其他信息。”
“人设中相同的内容，需要另到角色设置修改。”
“以前导出的备份中可能仍有这条信息。”
底部“取消”和红色危险按钮“确认忘记”。空间足够，警告不挤在一行。

03「处理结果」
一个题为“忘记此信息”的大状态卡，内部纵向三个明确分开的状态示例：
A 进度图标，“正在清理本地记录…”；副文案“清理完成前不会报告成功。”，按钮禁用“处理中”。
B 绿色对勾，“已忘记此信息”；副文案“本地清理已完成，来源原文仍保留。”，按钮“完成”。
C 红色感叹号，“清理失败，尚未完成忘记”；副文案“请重试，已完成的操作不会重复写入。”，按钮“重试”。不要把A/B/C画成同一时刻发生的步骤，需要状态标签。

04「纠正冲突」
弹窗标题“发现不同的称呼”。内容“已有有效称呼：小陈”“本次填写：阿达”。提示“请选择这次要保留的内容。” 两个可选卡片：“保留现有「小陈」”默认选中；“改用「阿达」并替代现有记录”未选中。底部“取消”“确认选择”。禁止自动静默覆盖。

05「明确删除共享资料」
弹窗标题“删除这条共享资料？”，范围标签“用户明确共享”。内容卡“工作日晚上学习 TypeScript”。说明“删除后，这条共享资料不再用于后续回复。”下一行“此操作只处理本条资料；人设和聊天原文需另行处理。”。底部“取消”，红色按钮“删除共享资料”。不要将整个共享资料库删除，不涉及多角色页面。

06「影响正在进行的回复」
聊天局部窗口标题栏“桌面陪伴”，聊天对象“六花”。一条用户消息“以后叫我小陈。”，一条六花部分回复“好呀，小陈，今天的学习…”。紧贴此回复的琥珀标签“未完成”，说明横条“记忆已更新；使用旧内容的回复已停止。”，次要说明“再次发送会生成一条新回复。” 底部输入框“说点什么…”与发送按钮。不得显示已完成或伪造后半句。

Constraints: 同一套暖白淡紫深蓝视觉语言。每个弹窗标题显著、按钮清楚、文案简短准确、字号大。全图只出现上述必要信息，禁止多角色、语音、好感数值、新建会话、清空聊天、未接入占位。不要写代码或技术实现标识。
