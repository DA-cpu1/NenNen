Use case: ui-mockup.
Asset type: 完整首版Windows桌面陪伴应用设置操作状态图册，用来补齐已有设置页按钮点击后的所有关键结果，不是新设置导航页面。
Reference: 暖白底、淡紫主按钮、深蓝字、Windows11细标题栏、中文清晰、与参考相同的成熟安静界面。无大型角色插画，必要时很小的同一六花头像即可。
Primary request: 生成2560x3000竖向高分辨率设计板，严格两列四行共8个大面板。顶部“19 / 凭据与设置保存状态”，图外右上“完整首版界面 · 设计稿”。每个面板有编号、标题，足够留白、大字可读。子状态要用分离卡片和“处理中/成功/失败”明确标签，表示互相独立的状态示例，不是同时发生。重点文案逐字正确，勿缩成小字。

01 更换凭据
弹窗“更换 API 凭据”，字段“新 API 密钥”，输入框只画圆点掩码“••••••••••••”，不要真实密钥，不画可用密钥字符串。辅助文案“保存成功后才会替换当前凭据。”。
按钮“取消”“保存新凭据”。

02 更换凭据：保存结果
三张纵向独立小卡：
“保存中”：转圈图标，“正在保存并更新凭据…”；保存按钮禁用。
“成功”：绿勾，“凭据已更新”；次要“后续请求使用新凭据。”，按钮“完成”。
“失败”：红色叹号，“凭据未更新，请重试”；次要“不能把未完成的保存显示为成功。”，按钮“重试保存”。
不要展示真实密钥。错误状态不可有成功勾。

03 删除凭据确认
弹窗“删除 API 凭据？”，说明“删除后无法请求模型；已有本地聊天记录仍可查看。”。
提示“不会删除聊天、记忆和人设。”。
按钮“取消”“删除凭据”，危险按钮为红色。
下面一条独立处理中示例：“正在删除凭据…”与禁用按钮。

04 删除结果与未配置模型
上半绿色小条“凭据已删除”。下面模型配置页局部状态：
“尚未配置模型”
“本地聊天记录仍可查看，发送消息需要重新配置模型。”
按钮“去模型与连接”。
下半单独红色失败示例：“删除失败，尚未完成”，按钮“重试删除”。成功和失败用分隔线及标签分开，不误以为同时存在。

05 配置保存失败
设置页局部，标题“模型与连接”。一条明显红色状态：“配置保存失败，尚未保存本次修改。”。
次要说明“请重试；填写内容仍保留。”。
按钮“重试保存”“取消修改”。禁止显示已保存或绿色成功勾。

06 未知用量与费用
用量与预算页局部。
状态标签“用量：估算”
说明“服务商未返回实际用量，已按保守估算计入限额。”
单独费用卡“费用：未知”，说明“尚未配置价格；未知不代表免费。”
不要显示零token或0元，不杜撰价格。这里是系统判断的标签，不是用户手动切换按钮。

07 价格保存反馈
标题“保存价格”，三个分离状态：
“保存中” 转圈，“正在保存价格…”。
“成功” 绿勾，“价格已保存，金额按配置价格估算。”。
“失败” 红色叹号，“价格未保存，请重试。”，按钮“重试保存”。
不能把估算金额标成供应商真实账单。

08 整理预算保存反馈
标题“保存整理预算”，小字当前输入“每日20次 · 输入+输出合计40,000 token”。
三个分离状态：
“保存中” 转圈，“正在保存整理预算…”。
“成功” 绿勾，“整理预算已保存”。
“失败” 红色叹号，“整理预算未保存；输入值仍保留。”，按钮“重试保存”。
不要画成已经达到每日上限，不更改聊天每日费用上限的未决状态。

Constraints: 六花单角色首版，与既有页面相同视觉。全部是真实最终产品UI局部状态，不是代码/骨架/临时占位。不要新模型选择器，不要技术管理页，不要语音/多角色/新会话/清空聊天。每个状态关键按钮、保存结果、失败文案清楚可读，8个面板都不能漏。
