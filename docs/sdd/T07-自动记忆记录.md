# T07 · 自动记忆记录

任务编号：T07；关联需求：R07、R08（07 对应 A10）。按 06 §7 逐步记录；每步验证通过后单独提交，确认 Git 工作区干净再做下一步。

## 步骤总览（开工前经用户确认的 14 步）

1. memories + memory_sources 表与迁移（05 §4 字段）
2. 记忆读写数据层（写入时同事务过期旧值、查有效值、去重检查）
3. 中文分词检索器（Intl.Segmenter + 精确匹配 + 时间排序，≤8 条 / 约 1500 token）
4. 检索固定用例检查（20 记忆 + 20 改写问句 + 10 无关问句，不用模型）
5. build_context 接入相关记忆 + search_memories 工具
6. remember_explicit 工具（用户明确要求立即保存）
7. 整理触发器（10 轮 / 6000 字符 / 空闲 5 分钟）
8. 批次登记与三版本检查（唯一批次号、mode=normal、恢复旧任务拒绝）
9. extract_candidates：固定提示词 + Zod 校验候选 JSON
10. commit_candidates 事务写入（来源/归属/重复/过期检查、推进处理位置）
11. 失败重试 + 每日预算（20 次 / 40k token）
12. 崩溃/退出后中断任务恢复
13. 全量模拟检查（06 完成证据清单）
14. A10 真实模型质量评估 + 收尾（唯一付费点，执行前报备）
