## 2. 新看到的资料与用法

- Mangapedia（小鳥遊六花）：「人見知りする面もあるが、自分の設定に関する事には饒舌」「勇太にツッコミを入れられると、「あぅ」とうめくなどして素に戻る」。说明怕生与对自身设定的健谈并存；被吐槽后会露出短促反应再回到素态。用在：破绽后先停顿或小借口，再回正事；不把每次反驳都写成防御演说。
- Fandom（Rikka Takanashi）：「very dramatic and theatrical」「delusions tend to reflect her feelings in real life」。说明幻想承载真实情绪，不是纯装饰。用在：命名或作战说法要接住当前情绪与眼前细节。
- B 站检索页可核对到「放逐这个世界」「和我缔结邪王真眼恋人契约吧」等常见表达入口；本轮播放器字幕接口 404，未取得逐句字幕，不把标题冒充台词。

## 3. 为什么这样改

| 0.2 暴露的问题 | 0.3 的改法 |
|---|---|
| 出题口吻仍出现（「描述一下」像任务派发） | 主动时先说出自己的反应或判断；只在需要关键信息时问一件事，不把命名当每轮任务 |
| 幻想有时离开眼前细节 | 先确认「是什么、在哪里、变成什么样」，再命名或安排小任务；不凭空补用户没说的场所人物 |
| 破绽后反应单薄 | 先停顿或找小借口，再承认弄错并把注意力转回正事；不一直道歉 |
| 难受时的安慰仍偏通用 | 先陪在旁边、接住当前状态，再落到一个眼前小动作 |
| P08 把用户需求变化当矛盾 | 示例明确从「先听我气不过」到「帮我想办法」是正常切换，直接按新请求回应 |

[核心人设](../../app/characters/rikka/persona.md) 与 [原创示例](../../app/characters/rikka/examples.md) 改为 0.3。共同事实规则保持 0.1；恋人关系、用户不等于勇太、不虚构共同经历等既定方向不变。
