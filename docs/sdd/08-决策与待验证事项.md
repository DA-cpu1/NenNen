## 4. 备选处理原则

- eve 若验证不满足本地桌面要求：先记录失败证据、已尝试方案、对体积/恢复/成本的影响。提出在同一 `CompanionRuntime` 接口下改用 AI SDK 的 Agent 运行能力，作为新的决策；本稿未同时批准或实现第二套运行框架。
- 更换运行实现不得改变用户数据归属、人设格式、记忆来源和删除规则。需重跑相关用例。
- 不为了满足某个框架偏好要求所有用户注册额外云账户，或默默将本地架构改为云服务。
- 不因为一个模型不支持工具就把工具假装成功；更换验证过的模型配置。

### C01 · 2026-10-18：eve 独立服务与内存密钥

- 为什么需要改变：eve 0.80.1 官方自托管方式是 `eve build` 生成独立 Node 服务。当前版本 `@ai-sdk/openai-compatible@3.0.71` 的 `languageModel(id, config)` 第二参数被运行实现忽略，造成请求缺少 Authorization；改用 provider 一级 `apiKey`，在 eve `step.started` 内创建模型后，固定模拟与真实调用均通过。
- 原方案 / 新方案：一个后台承载业务和 eve → 业务后台管理独立 eve 子进程；两跳 stdin 交付机密。带密钥的模型对象仅在执行步骤内存中使用，不写入工作流检查点。
- 影响的需求：R17（按实际执行结果报告）；R03（基础聊天）及后续记忆设计的权威记录仍为 SQLite，产品范围不变。
- 影响的设计、表、任务、验收：03 §3/§4、T01、V02；无需数据库表或迁移变更。新增固定输入进程检查，覆盖端口认证、重启和退出；正式 CompanionRuntime 仍按 04 在后续任务实现。
- 旧数据怎样保留：不读取或修改用户数据库；技术测试每次创建独立的可丢弃运行目录。正式恢复从 SQLite 重建，框架文件不作聊天依据。
- 费用、工作量和体验影响：多一个本机 Node 服务，需要管理端口与孙进程退出。内存占用和安装包体积仍待测。开发启动保留一次固定短消息自测，配密钥会消耗模型用量；本次成功调用两次的 token 和耗时见任务记录，不据此推算人民币价格。
- 状态：**已采纳；本地运行链路已验证**。用户已在本次会话同意执行分步方案及相关文档记录。T01 与 V02 整体尚未完成，不能据此宣称正式会话恢复或安装包通过。

### C02 · 2026-10-19：打包运行时用 Electron 客串 Node

- 为什么需要改变：希望复用 Electron 已携带的运行环境，避免再装入一份独立 Node。既有本机记录报告 Electron 44.9.0 的内嵌 Node 为 24.22.0，满足 eve 的 ≥24 要求，并有一次 better-sqlite3 内存库读写成功（报告运行时 ABI 149）。ABI 是原生驱动与运行程序相互调用时必须匹配的约定，单次加载成功不能证明其他运行时也兼容。本轮另核对已安装 13.0.3 的源码：`package.json` 依赖 `node-addon-api`，`binding.gyp` 设置 `NAPI_VERSION=10`，入口使用 `NODE_API_MODULE`，这些支持「本地这一版本采用 Node-API」；Node-API 是用于减少对特定 Node 版本依赖的一套原生扩展接口。撤回的是仅凭运行成功就推断机制、以及「跨 ABI 通用、安装版驱动已验证」的无边界结论；源码依据仍不能替代实际随包二进制的加载与读写。
- 原方案 / 新方案：安装包附带官方 Node 发行包 → 打包后用应用自身 exe 客串 Node 跑业务后台与 eve；开发环境不变（系统 Node）。用户已同意先验证这一方向，当前没有升级 Electron 的开发计划。退路条件：升级 Electron 后内嵌 Node 与 eve 或 better-sqlite3 不兼容时，评估自带官方 Node，并重新验证驱动，不能只改启动程序就假定兼容。
- 影响的需求 Rxx：无产品需求变化；影响 03 §2 运行环境口径与 V06 验证方式。
- 影响的设计、表、任务、验收：03 §2/§3；T01 已有安装包构建、免安装目录启动/请求送达记录及本机用户安装确认，但探针未核对完整模型回复，应用后台也尚未接入数据库；安装后完整回合、后台文件库写入/重开，以及无开发环境账户下的启动、驱动加载和读写仍待验证。数据库与记忆设计不受影响。
- 旧数据怎样保留：不涉及；本次整理不读取或改写用户数据库。
- 费用、工作量和用户体验影响：省去单独携带 Node 的文件，但没有同条件的两份安装包作体积对照，不再宣称实测减小约 30 MB。2026-10-22 新构建安装包 144,210,968 字节、SHA-256 `55B7311E…`（旧包 `0373e7…` 作废）。`npmRebuild: false` 目前保留，是否能从锁定依赖重新生成可用驱动仍待验证，按用户决定（2026-10-22）挂 T11 补做；不能用 N-API 推断无需重建。运行环境升级时须重新检查打包后台、eve 和数据库；开发态 `check:agent` 不能独自替代安装验收。
- 状态：**已采纳；T01 关闭（遗留挂账）**。win-unpacked 探针两轮已核对窗口、后台/eve、认证 200/401、数据库持久化（第二轮读回第一轮写入值）与完整模型回合（成功状态、回复字数、精确用量；回复原文按 03 §7 不进日志，逐字核对只在开发态做）；安装版在本机开发账户确认新建库、迁移登记、读写落盘、双开无第二窗口且无额外写入、退出零进程（2026-10-22）。无开发环境账户验收与卸载按用户意愿暂缓；`npmRebuild` 驱动复现与静默 `/S` 超时根因按用户决定挂 T11。
