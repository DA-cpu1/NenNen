- 为什么：导航是同一个窗口的固定入口，不应随着右侧页面改变排法和背景。
- 检查步骤与结果：`npm run typecheck`、`node_modules/.bin/electron-vite build` 均退出 0；`node .eve/ui-design-review.mjs step-1` 退出 0。

- 证据位置：`app/.eve/ui-design-SZLS6p/` 的 `result.json`、`chat.png`、`settings.png`、`memory.png`；固定资料、零模型调用。
