# T02 · 透明角色小样记录

任务编号：T02（06 §2 第一阶段）
关联需求：R01（透明、可拖动、可缩放、尺寸与挡鼠标区域一致、可恢复默认位置）；03 §3（透明窗、Ctrl 滚轮缩放、按透明度命中、位置保存相对屏幕、拔屏/缩放放回可见区）
开始前条件：T01 基础窗口贯通已关闭（提交 26fd290）

## 实现内容

- 桌宠窗口：无边框 + 全透明 + 关投影 + 不占任务栏，与 T01 状态窗并存；界面第二入口 `pet.html`；占位角色图为自绘 SVG（正式图片在 08 §3 未决，小样不代用户定稿，头侧与四角留透明区供命中验证）
- 鼠标命中：真机证实本机 Windows 对 **alpha=0 像素原生穿透、实心像素原生挡住**；据此未引入 `setIgnoreMouseEvents` + canvas 逐像素方案——目标机器上系统已提供该行为，重复实现只添复杂度；其他环境表现挂 T13 复验，失效再上兜底
- 拖动：手动拖动。preload 开第一扇固定口子 `petDrag`（只发开始/结束信号，不带坐标）；主进程定时读屏幕光标移动窗口，坐标不经进程传递、无多屏 DPI 换算。不用 CSS `app-region: drag`——它把区域变系统标题栏，吞掉右键与点击，而 01 §5/T05 都还要用这两个事件
- 缩放：Ctrl+滚轮每档 ×1.1，限幅 0.25～3；「钉住脚底」缩放（底部中点不动）；窗口同步收缩，边缘始终紧贴角色图（R01 命中区域一致）
- 右键菜单：「恢复默认位置和大小」（主屏工作区中央 + 原始尺寸）
- 位置持久化：迁移 v2 建 `app_settings`（照抄 05 §2 样稿 DDL）；服务 `/window-state` GET/PUT，Zod strictObject 关卡（03 §2）；拖动结束、每档缩放、恢复默认后保存
- 恢复与可见性：启动时读回保存位置，经 `clampPetBounds` 拉回可见区后落位（四道防线：请求失败/未存过/格式不过关/完全不可见都停在默认位）；`display-metrics-changed` / `display-removed` 当场拉回可见区

## 已知问题与取舍

- 启动时角色先在默认中央位出现，后台就绪后（约 3～7 秒，后台先起 eve 再起服务）跳到保存位置。取舍理由：宁可先出现再挪窝，不让角色迟到；T05 优化启动顺序
- 界面进程若在拖动中途崩溃，「结束」信号丢失；兜底是窗口关闭/退出时清理，黏光标最坏场景未在真机复现过
- alpha=0 原生穿透仅本机验证；T13 多环境复验，失效时补 `setIgnoreMouseEvents` 方案
- 多屏真机验证未做（本机单屏），clamp 逻辑由固定输入用例覆盖；挂 T13
